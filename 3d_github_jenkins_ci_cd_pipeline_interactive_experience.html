    Complete GitHub & Jenkins CI/CD Connection Blueprint

    Production Webhook Configuration, Credentials & Pipeline Architecture

    Bi-Directional Event & Status Flow
    1. Developer Push
    Commits code & runs git push origin main
    2. GitHub Webhook
    Fires signed HTTP POST JSON to /github-webhook/
    3. Jenkins Pipeline
    Pulls repo, executes Jenkinsfile & posts status check back
    4. Docker & K8s
    Builds container image, runs tests & rolls out to Production
    A GitHub Repository Setup
    1. Generate a GitHub Personal Access Token (PAT) or GitHub App with repo and admin:repo_hook scopes.
    2. Navigate to Repository → Settings → Webhooks → Add webhook.
    3. Set Payload URL to: https://jenkins.yourdomain.com/github-webhook/ (trailing slash is mandatory!).
    4. Set Content type to application/json and configure a shared HMAC Secret.
    5. Select "Just the push event" and "Pull requests".
    B Jenkins Controller Setup
    1. Install the official GitHub Integration Plugin, Git Plugin, and Docker Pipeline Plugin.
    2. Add your GitHub PAT in Manage Jenkins → Credentials → Global (Kind: Secret text or Username with password).
    3. Create a Pipeline or Multibranch Pipeline job.
    4. Under Build Triggers, enable GitHub hook trigger for GITScm polling.
    5. Set Pipeline Definition to "Pipeline script from SCM" pointing to your repository's Jenkinsfile.
